02 / What It Does

D3.js is an open-source JavaScript library for making data-driven graphics in the browser. It lets data control HTML and SVG elements directly. Instead of using a fixed chart template, a designer can write code that connects data, visual form, interaction, and the webpage.

Data DOM SVG / HTML Interaction Reader

Data binding

Connects arrays or structured data to page elements, making data the driver of visual form.

Data joins

Defines enter, update, and exit states between data and visual elements.

Scales and shapes

Convert abstract values into positions, sizes, colors, paths, and readable geometry.

Transitions

Animate changes between states so viewers can follow how data changes over time.

03 / Context

Before D3, many visualization tools hid the final graphic inside toolkit-specific systems. D3 took a different approach. It used the browser's normal document structure, especially HTML and SVG, so designers could inspect and change every visual element.

D3 also grew out of earlier visualization research, especially Protovis. D3 moved closer to the normal language of the web, making custom websites, journalism, maps, diagrams, and interactive data graphics more flexible.

04 / Why It Matters
  1. It treats the browser as a visualization medium.
  2. It lets data generate visual form instead of only filling a fixed chart template.
  3. It connects academic visualization research to public web practice.
  4. It created a large open-source community of practice.

D3 influenced research, data journalism, civic technology, and creative coding. Its weakness is also its strength: because it is low-level and flexible, it can be difficult for beginners.
