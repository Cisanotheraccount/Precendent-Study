Part 2: Layers of Analysis

Ontological Analysis

D3.js exists as more than a charting library. It is made from relationships between data, browser documents, code, visual elements, examples, documentation, and a community of practice. Its main building block is the connection between data and the DOM.

Move near a floating term to see how it works inside D3.js.

Historical and Contextual Analysis

D3.js appeared in 2011, when web browsers were becoming important spaces for interactive graphics. The project responded to older visualization tools that often hid the underlying visual structure behind fixed abstractions. Instead, D3 gave designers and developers direct control over standard web elements. Its audience included researchers, web developers, visualization designers, journalists, and civic-data practitioners.

Visual and Aesthetic Analysis

D3 does not have one fixed visual style. Its visual language is procedural and data-driven: forms are generated from data and code. Its examples often use clear geometric shapes, maps, networks, axes, motion, and interaction. This places D3 within information visualization, computational design, web graphics, and data journalism.
